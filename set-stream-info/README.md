# set-stream-info

Plugin de OBS Studio para actualizar automáticamente el **título**, **descripción** y **categoría/juego** de la transmisión.

## Estado
Estructura inicial creada. Pendiente de ajustar la integración con la API de Twitch/YouTube o credenciales.

## Instalación
Ejecuta `install.ps1` como Administrador para copiar el script a la carpeta de scripts de OBS Studio.
