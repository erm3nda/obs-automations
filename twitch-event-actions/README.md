# Twitch Event Actions

Plugin unificado de OBS para reaccionar a eventos de Twitch.

## Paneles actuales

- **Chat**: configuración de eventos de chat y fuente de texto.
- **Suscripciones**: configuración de eventos de suscripción y fuente/escena.

Ambos paneles comparten una única configuración de conexión Twitch. El motor se ampliará después con follows, bits, raids, puntos del canal y otros eventos.

## Instalación

Ejecuta `install.ps1` como Administrador o usa `install-all.bat` desde la raíz del repositorio.
